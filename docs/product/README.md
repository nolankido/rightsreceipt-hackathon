## Reading order

1. Read `PRODUCT_BRIEF.md` to understand the user problem and competitive position.
2. Read `MVP_SCOPE.md` to understand exactly what the hackathon release includes and excludes.
3. Read `ACCEPTANCE_MATRIX.md` to understand what must be proven and which turn owns the evidence.
4. Read `USER_JOURNEYS.md` to understand actor routes, screen behavior, state presentation, and the judge path.
5. Read `VISUAL_SYSTEM.md` to understand tokens, components, responsive behavior, and accessibility expectations.
6. Read the root `PROJECT_STATUS.md` for the current implementation truth.

The product direction, MVP boundary, interaction contract, and visual baseline are frozen. Turn 007 creates the executable monorepo and shared UI foundations without expanding the product scope or representing unfinished screens as complete.
