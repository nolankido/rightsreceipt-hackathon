# Turn 120: Make the full release failure actionable without exposing logs

**Date:** November 5, 2026 UTC  
**Status:** Implemented and locally tested. The complete Node 22 release remains unverified.

## Why this matters

The internal hackathon cutover is blocked until the exact full release verifier runs on the frozen source with Node 22.13+ and pinned pnpm. The clean-checkout wrapper preserved detailed failed-stage evidence, but returned only the generic `release_verification_failed` code. On a Windows operator machine this obscured the first actionable failure and forced manual inspection of private JSON and logs even for a simple lockfile or stage timeout diagnosis.

This workspace has Node 24.22.1 and pnpm 11.25.0. Running `node scripts/clean-release-checkout.mjs --export-public` here correctly returns `node_22_required` before creating a clone. This does **not** satisfy the required full Node 22 release gate. The improvement below prepares useful diagnostics for the genuine run.

## Changes

- Add an explicit allowlist of failure codes generated by `release-candidate-verify.mjs` and `tracked-source-identity.mjs` to `scripts/clean-release-checkout.mjs`.
- For a failed complete release with valid commit-bound evidence, include `diagnostics.failureCodes`, `diagnostics.firstFailedStage` (1 through 4 or null), and `diagnostics.unknownFailureCodesPresent` in the existing outer JSON result.
- Suppress arbitrary failure strings, private stdout/stderr, environmental values and URLs. The diagnostic array deduplicates valid codes, and unrecognized values are represented by a boolean only.
- Require the failed record's commit, schema and `full` mode to match the wrapper's exact source identity before reporting diagnostics. Leave successful release result structure unchanged, with no `diagnostics` property. Invalid, stale or missing evidence still fails closed and is never interpreted as a passing release.
- Extend the clean-checkout regression suite for Stage 3 timeout, preflight-only failure, duplicate identifiers, invented secret-bearing diagnostics, malformed evidence and mismatched commit/mode records.
- Update [the Windows release runbook](../submission/CLEAN_CHECKOUT_RELEASE.md) and [cutover checklist](../submission/FINAL_CUTOVER_CHECKLIST.md).
