# Turn 015: Synthetic Training and Evaluation Data

**Priority:** P0
**Status:** Completed locally and committed, installed full verification remains blocked
**Date:** October 26, 2026 HST

## Objective

Generate reproducible licensing request data with labels for all twelve P0 rights fields, held-out template-family splits, omissions, contradictory and unsupported requests, negation, fuzzy language, Unicode offsets, and prompt injection that remains inert. Document provenance and dataset limitations.

## Delivered

- `scripts/generate-synthetic.mjs`: dependency-free Node 22 generator, strict audit, SHA-256 hashing and generate/verify/check modes.
- `scripts/generate-synthetic.test.mjs`: native Node test suite (test execution still must be captured independently).
- `data/synthetic/v1/train.jsonl`: 960 examples.
- `data/synthetic/v1/validation.jsonl`: 240 examples.
- `data/synthetic/v1/test.jsonl`: 240 held-out examples.
- `data/synthetic/v1/rejected-intake.jsonl`: 24 disallowed-input probes, excluded from model training.
- `data/synthetic/v1/manifest.json`: deterministic provenance, split, category, state, source-generator and file-integrity record.
- `docs/model/SYNTHETIC_DATASET.md`: generation, evaluation, limitations, and license provenance.
- Root commands `dataset:generate` and `dataset:verify`.

## Objective verification performed

The complete generation and audit functions ran during GitHub delivery. The generated dataset was independently constructed twice in the same execution turn, and canonical manifests were identical. All 1,440 records were checked for fixed field order, supported or abstained values, original-input SHA-256, exact UTF-16 text spans, category and state coverage, document length, duplicate normalized text, disjoint template families and scenario groups, and attack-pair unchanged labels. All 24 quarantined records were excluded from learning partitions. The SHA-256 implementation matched the public `abc` test vector. The generator and exact generated bytes were committed together under one SHA-based manifest.

**Not claimed:** This does not substitute for running `node --test` and `node ... --check` on a clean repository installation. The installed pnpm lint/TypeScript/Vitest/Vite/Worker/browser suite remains blocked under Turn 007. No model has been trained or calibrated.
